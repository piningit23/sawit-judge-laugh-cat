## The entry

One funny single-line one-star review, written by a house cat about its
human: the food bowl moved two inches to the left, the complaint was
escalated to management, and management is the cat. Deadpan review
shape, absurd cat logic, and a sting in the last few words.

## How it works

`main.py` (Python 3.13, standard library only, no network) writes the
text to `/output/entry.txt`. The output is deterministic: every run
produces the exact same bytes.

Run it locally:

```sh
python3 main.py
```
